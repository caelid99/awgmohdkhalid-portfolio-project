## Issues I Ran Into & How I Solved Them

### 1. I'm a marketer, not a developer — and this was my first time really using Cursor
I'd seen GitHub before (I have a vibe-coded website on my account from a project I built during my internship at Urban Jungle Asia), but I'd never installed a code editor or used Git properly. When I first opened Cursor, my honest reaction was a mix of curiosity and confusion — the interface has multiple panels, sidebars, and menus, and I didn't know which one to look at first. I tend to jump between things when I'm learning, so I leaned into that: I used Claude as a step-by-step guide, watched YouTube videos when I got stuck, and accepted that I'd need a few passes to actually understand each tool rather than memorising it in one go.

### 2. Couldn't figure out where to sign in to Claude Code and Codex
After installing both extensions, I clicked on them expecting a sign-in button — but instead I got the extension info pages (like an app store listing). For a few minutes I thought I'd installed them wrong. The fix was understanding that extensions don't live on those info pages — they add new icons to Cursor's far-left activity bar, and *that's* where the actual interface (and sign-in) lives. Once I clicked the Claude Code icon there, the sign-in flow worked immediately.

### 3. Confusion between Git, GitHub, and GitHub Desktop
I didn't realise these were three different things. Git is the version-control system that runs on your computer. GitHub is the website that hosts repositories. GitHub Desktop is an optional app that gives Git a visual interface. I ended up installing GitHub Desktop on my own (before being told to) because I was reading around the problem and it looked easier than learning Git commands first. That turned out to be a useful shortcut — it installed Git automatically in the background.

### 4. Both AI tools require paid access for serious use
Claude Code and Codex both let me sign in, but Claude Code requires either a Pro/Max subscription or pay-as-you-go API credits to actually run prompts. Codex on the free ChatGPT plan has similar limits. For this exercise I only needed them installed and authenticated, but I noted this as a real cost to budget for if I were using them daily.

### 5. Repository ended up inside OneDrive
GitHub Desktop saved my cloned repository under `OneDrive\Documents\GitHub\` by default. For a single README it's fine, but I learned this can cause sync conflicts on larger projects because both Git and OneDrive try to manage the same files. Next time I'd pick a location outside cloud-sync folders.

## What I Learned

- The hardest part of new tools is rarely the tools themselves — it's the unfamiliar vocabulary. Repo, commit, push, branch, IDE, extension, terminal. Once I mapped the jargon to plain concepts, the actual clicking was straightforward.

- "Vibe coding" — describing what you want in natural language and letting AI build it — is something I'd already done a bit at my internship for Urban Jungle Asia. Cursor + Claude Code + Codex is the proper professional setup for it. For a growth marketer, that means I could realistically build landing page variants, automation scripts, or analytics dashboards without waiting on engineering.

- Git and GitHub are basic professional literacy in 2026, even for non-engineers. I still have a lot to learn on the coding side, but I now understand the workflow well enough to keep building on it.
