## Post 1 — 15 June 2026 — 45 likes, 18 comments

URL: https://www.linkedin.com/posts/kevinindig_ai-trusts-a-different-set-of-sources-for-activity-7472249744724156417-dz3F

AI trusts a different set of sources for every topic. There's no fixed list it pulls from. The off-property authority you build has to be topic-specific, too.

I looked at AI citations across a sample of topics. For invoicing questions, for example, competitor domains hold 33.5% of what AI cites. For starting a business, the same source type holds 7%.

So building mentions everywhere wastes your budget. Lift a PR plan from a neighboring topic, and you miss the set AI actually pulls for yours.

Owned content still matters, but it's one of your weaker inputs. The publications, experts, and competitors that mention you carry more weight, because the model didn't have to take your word for it.

Map the specific domains AI already cites for your topic, then earn your way into that set.

URL: https://www.linkedin.com/posts/kevinindig_a-prompt-tracker-that-runs-each-prompt-once-activity-7471161915302563840-I-ln

A prompt tracker that runs each prompt once is measuring volatility, not visibility.

I looked at 815,000 prompt-page pairs with AirOps. After the same prompt ran 3x in ChatGPT, only 2.2% of citations remained.

Accuracy improves when you treat each prompt like a sample: run it 3-5 times, report confidence intervals, and keep the raw answers for audit. The goal is to measure variance instead of avoiding it.

## Post 5 — 9 June 2026 — 62 likes, 20 comments

URL: https://www.linkedin.com/posts/kevinindig_good-prompt-tracking-starts-with-sample-design-activity-7470197035565002752-T8ow

Good prompt tracking starts with sample design.

For your average B2B SaaS CRM category, I'd start with ~40 seed prompts: 12 brand, 12 category, and 16 problem prompts. The problem prompts matter because that is where purchase intent usually lives.

Then I'd run each prompt 5x per platform every week. ChatGPT, Perplexity, Gemini, and Google AI Overviews should each get their own score because aggregation hides how differently the engines behave.

The panel also needs personas. CFO, IT, and marketing buyers evaluate the same CRM category through different criteria, so averaging them together hides where a brand actually wins or loses.

The metric set should include mention rate, citation rate, average position, sentiment, and the attributes attached to each mention, all with confidence intervals.

That is how prompt tracking becomes more accurate: each answer becomes one sample in a designed panel, not one truth in a dashboard.

## Post 6 — 8 June 2026 — 109 likes, 32 comments

URL: https://www.linkedin.com/posts/kevinindig_ai-answers-are-probabilistic-but-prompt-activity-7469704803720482816-DO-D

AI answers are probabilistic, but prompt tracking can still become more accurate.

The backlash against prompt tracking gets one thing right: one prompt run is not enough. 5 people can run the same prompt and get 5 different answers.
The wrong conclusion is that prompt tracking is useless. The better conclusion is that prompt tracking needs better sampling.

Run prompts multiple times. Keep platform scores separate. Add confidence intervals. Track personas and follow-up journeys. Store raw answers so you can audit whether the issue is the model, the scorer, the scraper, or the prompt.

Prompt tracking will not become keyword tracking. It will look more like polling.

I get why people dunk on prompt tracking. Run the same prompt a few times and the answers move. If you treat one run as a score, the whole thing feels fake fast.

But, I don't think that's the right read. The better question is what prompt tracking would look like if we stopped pretending it was rank tracking. More like polling: repeated runs, fixed sampling, confidence bands, separate platform panels, personas, and raw answers you can audit.
